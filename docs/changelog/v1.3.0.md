# v1.3.0

## Added
- **Drop the download as it is.** Drag a livery `.zip`, `.rar` or `.7z` (or the already extracted folder) onto the Apply screen and the app extracts it for you into a temporary folder, then carries on as usual. The temporary files are deleted when you leave the screen, and your download is never changed. Archives are opened defensively: files that try to escape the extraction folder, absurdly large archives and damaged or password-protected ones are refused with a clear message. Password-protected archives and multi-part `.rar` sets still need to be extracted by hand.
- **Setup check.** The folder screen now explains common mistakes instead of silently misbehaving: Official and Community pointing to the same folder or inside each other, the `Official2024` folder chosen instead of its `Steam`/`OneStore` subfolder (with a one-click fix), a folder that only contains liveries, folders that differ from the ones MSFS itself uses (for example after moving the game to another drive), a Community folder that can't be written to, and MSFS 2020 folders. The same check re-runs whenever the saved folders go stale.
- **Diagnostic report.** *Options > Export diagnostic report...* writes one `.zip` you can attach to a bug report (setup, detected aircraft, what the app installed, the recent log). You choose where it goes; nothing is uploaded; textures and models are never included; your Windows user name is hidden by default. *Copy diagnostic summary* puts a short version on the clipboard.
- **Aircraft list filters.** Chips for "With my liveries" and "With Career activities" (with counts), and a badge on each card that has Career activities.
- **Preview summary and disk space check.** The preview shows how many files and how much space the livery adds, warns when the drive that holds your Community folder is running low, and refuses to start a copy that can't possibly fit.
- **Notes that explain results that look like bugs**, for example when none of your aircraft has Career activities, or when aircraft that aren't fully downloaded in the in-game Content Manager seem to be missing.
- Installed packages: an empty state that explains the screen, packages sorted by aircraft, an *Open folder* button, and a confirmation inside the card before anything is removed.
- A progress bar while a livery is being copied or extracted, an *Open package folder* button on the success screen, and drag-and-drop highlighting.

## Changed
- The "MSFS is running" notice now goes away on its own when you close the game.
- Choosing a folder that has no usable livery now says why (a compressed download, an old FSX/P3D-format livery, a folder one level too high...) and keeps the livery you had already loaded.
- The log file now rolls over at about 1 MB (three files at most) and no longer repeats the "Scanned N aircraft" line on every screen change. *Open logs* opens the log folder when no program is set up for `.log` files.
- Dark, slim scrollbars to match the rest of the app.

## Fixed
- The confirmation screen listed the wrong file paths for a Dynamic Registration livery applied to a Career activity (it showed the base folder next to the activity folder instead of inside it). The package that was actually written was already correct.
- The warning for a livery that belongs to another aircraft showed empty parentheses when the aircraft couldn't be detected.
- The "Use Dynamic Registration" box no longer appears ticked on liveries that don't have that variant.

## Internal
- 340+ automated tests, run on every push, covering the livery recipes, the per-aircraft fixes (each one is checked to run only for its own aircraft), the new setup check, the diagnostic report and the archive extractor.
- Added SharpCompress (MIT) for `.rar` and `.7z`: about 0.7 MB more in the download.
- Nothing in how a livery package is built changed, so existing installed packages and the in-game result are exactly as before.
