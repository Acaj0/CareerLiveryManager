# v1.2.3

## Fixed
- A livery applied with "Use Dynamic Registration" on an aircraft with no Career activity (e.g. Cessna Citation Longitude, CJ4) could show missing/wrong-colored textures on parts the registration variant doesn't cover itself (falls back to the base livery for those). A refactor in v1.2.1 broke the fallback path for these aircraft specifically - activity aircraft (737 MAX, C172, Caravan, etc.) were never affected.
