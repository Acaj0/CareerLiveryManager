# v1.3.5

## Changed
- **Airbus A320neo, A321 and LVFR A330-900: your livery now asks for priority in Career.** There are reports of liveries on these aircraft showing in Free Flight while Career picks a different one. The app now installs the livery in a folder starting with `!000000000_`, names it `!000 ...` and adds the Career tags (Freelance, airline licence) to it. This has not been confirmed in-game yet - if you fly one of these in Career, please report what you see.

  Apply your livery again after updating: liveries installed with an earlier version are not changed.

  Only these three aircraft are affected. The default A330 and every other aircraft work as before.
