# v1.1.2

## Added
- "Detect automatically" button on the setup screen: finds your `Official2024` and `Community` folders by reading MSFS's own `UserCfg.opt`, without needing to browse for them by hand. Works for Steam, Microsoft Store, and Xbox app (Game Pass) installs.
- [Game Pass / Xbox app setup guide](../GAME_PASS_SETUP.md), linked directly from the setup screen, for the case where auto-detect doesn't find your folders.
- This changelog.

## Fixed
- Clearer error message when the Official2024 path doesn't validate, pointing Game Pass users at the new detection/guide.
