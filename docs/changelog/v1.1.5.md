# v1.1.5

## Changed
- Feedback/changelog/roadmap links now point to clm.antoniodeabreu.dev.

## Fixed
- The setup screen could grow taller than the window (especially with a smaller window, high DPI scaling, or just after we added the "Detect automatically"/Game Pass guide row) and had no scrollbar, so the "Continue" button could end up below the visible area with no way to reach it. This meant the app never saved your folders and always reopened to an empty setup screen. The setup screen now scrolls, and the window also has a minimum size so it can't be shrunk small enough to hide controls on any screen.
- As a safety net: if the saved Official content folder ever becomes invalid between screens (deleted, renamed, moved drive, etc.), opening the aircraft list now sends you back to setup with a clear message instead of crashing with a raw error.
- The Community folder is now validated on setup too (empty path, or a folder that can't be created) instead of only the Official one.
- Setup now logs what "Detect automatically" found (or didn't find) and what got saved on Continue, to make future support requests easier to diagnose from the log alone.
