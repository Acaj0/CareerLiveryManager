# v1.3.2

## Added
- **Pilatus PC-12 NGX: a livery per role (experimental).** The PC-12 now has Medevac, Cargo Transport and Private Charter (VIP) entries, plus a "Default" entry that works exactly like before (one livery for the whole aircraft). The roles are matched through the official livery folder names (`_m`, `_c`, `_vip`), and any part your livery doesn't cover is filled in invisibly, so the official medevac cross and decals don't show through. This has not been confirmed in-game yet - if you own the PC-12, please report whether each role picks up its livery.

## Fixed
- Replacing a livery could fail with "Access to the path 'panel.cfg' is denied" and leave a half-deleted package behind, when a file in the old package was marked read-only. Packages are now removed even if they contain read-only files.
