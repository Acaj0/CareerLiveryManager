# v1.2.0

## Added
- **Career activities support**: some aircraft use a different livery per Career job (Cargo Transport, Flightseeing, Skydive, VIP/Charter, etc.) instead of one livery for the whole plane. Career Livery Manager now detects this automatically and lets you set a different custom livery per activity - see `CAREER_LIVERY_RESEARCH.md` sections 18-19 for how this was reverse-engineered and validated. Detected on:
  - **Cessna 172SP G1000** - Aerial Advertising, Cargo Transport, Flightseeing, Skydive Aviation, Default
  - **Cessna 208B Grand Caravan EX** - Cargo Transport, Medevac, Skydive Aviation, Default
  - **Boeing 737 MAX** - Commercial Flights, Private Charter, Default
  - **Air Tractor AT-802** - Aerial Firefighting, Agricultural Aviation, Default
  - **Airbus H125** - Agricultural Aviation, Cargo Transport, Flightseeing, Search & Rescue, Default
  - **CubCrafters XCub** - Aerial Advertising, Flightseeing, Search & Rescue, Default
  - **Canadair CL-415** - Aerial Firefighting, Default
  - **Electra ES-30** - Commercial Flights, Default

  A new screen shows the activities an aircraft supports; pick one to customize it, the others stay as they are. Applying a livery to one activity (e.g. Cargo) never touches another activity's livery (e.g. Flightseeing) on the same aircraft. Installed Packages now shows which activity each installed livery belongs to.
- Redesigned the aircraft selection screen as a responsive grid (columns adapt to window width) instead of a list.
- The aircraft list now falls back to a livery folder's own thumbnail when a package has no usable top-level marketing image.

## Fixed
- A "installed" badge with more than one package now shows a count (e.g. "INSTALLED ×2") instead of just "INSTALLED".
- Several official aircraft (Bonanza G36, UH-1H, VL3, Volocity, and others) ship a generic gray "Placeholder" image instead of a real photo as their marketing thumbnail. The aircraft list now detects that specific placeholder and shows a real livery photo instead.
