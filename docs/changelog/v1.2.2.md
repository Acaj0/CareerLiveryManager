# v1.2.2

Everything in this release is scoped to the 737 MAX specifically - other activity-supported aircraft (C172, Caravan, AT-802, H125, XCub, CL-415, ES30) are unaffected.

## Fixed
- A livery missing coverage for one of the plane's less obvious parts (the wing root, landing gear, tail, or the fuselage entirely on a texture-only livery) no longer shows a patch of the wrong color or a demo airline's own branding - it's now rendered invisibly instead, blending in seamlessly with whatever livery you applied. This took several passes to get fully right:
  - Official's own 3D geometry ships zlib-compressed in a way the livery system can't read as-is; it's now properly decompressed into a working format.
  - A part borrowed from Official to fill a gap needed its materials rewritten to be truly invisible (a plain white recolor still showed as a visible seam); some of those materials also had a self-illumination property that ignored transparency, and others had no color property to override at all (defaulting to fully opaque) - both are now handled.
- Some multi-registration livery packs (a shared "_common" folder holding the real geometry/textures, with each registration just pointing at it) made the plane show up completely blank/white, because that shared folder wasn't being copied into the package. It's now detected and copied automatically.
- Installing the same livery for more than one Career activity (e.g. Commercial and Official) showed identical, indistinguishable names in Free Flight - each one now gets an activity label so you can tell them apart.

## Added
- Applying a livery now logs exactly what the app had to backfill or adjust to make it work, so a bug report's log file shows the full picture without needing to re-send the livery file.

## Known limitation (not a bug)
- A livery that only changes the engine (and sometimes the wing "shark fin") while the rest of the plane stays default is very likely a partial/registration-only repaint, not a full one - the fallback mechanism only fills in what's actually missing, so an incomplete third-party livery will still render incompletely. Try a livery explicitly labeled as a full repaint, or apply with "Use Dynamic Registration" unchecked to test the base folder on its own.
