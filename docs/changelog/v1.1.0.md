# v1.1.0

The first version with the auto-updater. Versions before this one (v1.0.0) have to be downloaded manually; from this version onward, updates are offered automatically.

## Added
- Auto-updater: checks GitHub Releases on startup and offers a one-click update (download, checksum verification when the release publishes one, and a small bootstrap script that swaps the install folder and relaunches the app). Can be turned off from Options.
- Applying a new livery to an aircraft that already has one now automatically removes the previous Career Livery Manager package for that aircraft, instead of leaving it behind in Community. The new package is always installed before the old one is removed, so a failed apply never leaves an aircraft without a livery.
- App version shown in the footer.

## Changed
- Renamed the executable to `CareerLiveryManager.exe` (it was `CareerLiveryManager.App.exe`) to match the README's instructions.
