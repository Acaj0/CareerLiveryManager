# v1.3.3

## Changed
- **Pilatus PC-12 NGX: back to a single livery for the whole aircraft.** The per-role entries (Medevac, Cargo, Private Charter) added in v1.3.2 are removed. In-game testing showed that the game does not pick a livery per role for this aircraft (the livery chosen for one role showed for every mission type) and that the override could leave the aircraft unpainted. The PC-12 works as it did before v1.3.2.
- If you installed a PC-12 role livery with v1.3.2, applying a livery to the PC-12 now also removes that leftover package, so it no longer overrides the official role slots.
