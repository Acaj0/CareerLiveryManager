08 — Rules
Do
Keep the accent for actions, selection, progress and active state only. Use one surface level per screen. Radius 6px for controls, 10px for surfaces, 22% for the icon tile. Shadows: none, or a single 1px border.
Don't
No gradients on the mark, no glow, no rotation, no outline versions of the delta, no accent-coloured body text, no second typeface beyond the mono used for paths and codes.
Assets to cut
icon.ico (16/24/32/48/64/128/256), icon.png 512, avatar 460, hero 1280×640, favicon 32. All from the same source SVG — ask and I'll export them.
